# 경기 중 조합 입력

전장·내 역할·양 팀 조합·추천 5명을 한 화면에 배치했다. 사이드바, 장식용 맵 이미지, 역할별 중복 순위, 슬로건, 상시 노출되던 긴 추천 문장을 제거했다. 근거·출처·원본 통계는 접힌 상세 영역에서 확인한다.

## 입력과 교체

- 자리를 클릭하고 영웅 버튼을 클릭하면 즉시 반영한다. 팝업과 확인 단계는 없다.
- 빈 자리의 첫 입력만 다음 빈 자리로 이동한다. 이미 채운 자리를 교체하면 해당 자리에 머문다. 아군·상대 모두 같은 방식이다.
- 이름·영문 ID·한국어 초성으로 검색하고 Enter로 선택한다. 검색창에서 위/아래 화살표로 후보를 바꾸며 F2로 검색창에 포커스한다. 한글 조합 중 Enter는 선택으로 처리하지 않는다.
- 비우기는 선택한 자리만 지운다. 조합 초기화는 맵과 역할을 유지하고 양 팀 및 진영을 초기화한다. 되돌리기는 마지막 변경 1회를 복원한다.
- 같은 팀 중복은 막고 상대 팀과의 미러 픽은 허용한다. 내 자리는 추천용으로 비워 둔다.
- 조합을 바꾸면 로컬 추천을 즉시 재계산한다. 이전 AI 결과는 폐기하며, 이전 조합에 대한 늦은 응답도 적용하지 않는다. AI 재정렬은 버튼을 눌렀을 때만 요청한다.
- 창 전환과 설정 화면 왕복/설정 저장은 조합을 유지한다. 앱 종료·새로고침 후 조합 복원은 제공하지 않는다. 메타 교체 시 현재 자료에 없는 영웅만 제거한다.

## 검증

35개 자동 테스트 통과. 빠른 입력 관련 5개는 다음 빈 자리 순환/완료, 초성·영문 검색, 설정 갱신 시 조합 유지, 메타 교체 시 잘못된 참조 제거, 아군 교체 후 추천 후보 갱신을 확인한다.

공통 렌더러 브라우저에서 9명 연속 입력, 양 팀 교체 후 자리 유지, 중복 차단/미러 허용, 비우기/초기화 되돌리기, 설정 저장 후 조합 유지, 상성에 따른 실제 로컬 점수 갱신을 확인했다. 상대 탱커를 로드호그로 교체하자 아나 점수가 51.4에서 52.0으로 바뀌었으며 아군을 아나로 교체하면 아나는 추천에서 제외됐다.

1280×720과 최소 창의 콘텐츠 영역을 고려한 900×610에서 가로/문서 전체 세로 넘침 없음. 작은 창의 영웅 목록 및 확장 근거는 내부 스크롤을 사용한다. 키보드 선택 항목도 목록 안에서 보이게 이동한다. 브라우저 오류 로그 없음.

Windows 패키지의 실제 창 로드/loopback 서버/DPAPI 암복호화는 별도 격리 데이터로 스모크 검증한다. 실제 전체화면 게임과의 Alt-Tab, Windows 한글 IME의 실제 조합 입력, 실제 모델 호출 및 추천 정확도는 별도 실사용 검증 범위다. 이번 작업의 실제 모델 호출은 0회다.
