# 프로젝트 방향 · 2026-09-29 갱신

개인 Windows 데스크톱 앱. 일반 PC 5대5 역할 고정 경쟁전에서 맵·티어·아군 시너지·상대 대응을 고려해 영웅을 추천한다. 사용자는 대부분의 영웅을 사용할 수 있다. 웹 서비스 배포는 하지 않는다.

## 확정된 AI 경계

- 메타 조사는 이 Codex 데스크톱 대화에서 수행하고 검토한 JSON을 코드 또는 앱에 직접 주입한다.
- 앱의 AI는 저장한 메타와 사용자가 입력한 경기 데이터에 한정해 상위 5명을 정렬하고 이유를 설명한다. 앱 내 메타 조사·웹 검색 API는 제거한다.
- 개인 키를 Windows DPAPI로 암호화한다. Gemini 무료 티어 지원 모델을 기본으로 하고 OpenAI는 명시적으로 선택할 때만 사용한다.
- 실제 모델 호출은 별도 요청 범위/횟수 승인 후에만 검증한다. 이번 작업은 실제 AI 호출 0회다.

## 메타 품질

현재 메타는 공식 통계 기반 초기 비교치이며 예측 성능은 검증되지 않았다. 공식 통계만으로 전체 상성·조합 승률을 만들 수 없다. Astra는 근거 종합과 조건부 해석에 사용한다. Counterwatch는 상성 보완 우선 후보이고, OWTICS는 추세/맵 자료의 교차 확인에 활용할 수 있다. 공개 사이트와 지원되는 공개 API를 구분한다. 검토 세부사항은 META_DATA_REVIEW.md에 있다.

KR 사용 환경이라는 사용자 표현은 보존하지만 현재 데이터는 아시아이며 한국 전용이라고 표시하지 않는다. 2026-09-29 공식 경쟁전 통계 전장 30개와 수집 30개가 일치한다. 스타디움 전용 5개와 일반 경쟁전에서 제외된 격돌 2개는 기본 추천 목록에 넣지 않는다.

## 남은 품질 고도화

상성/시너지의 관측 근거와 분석 근거 분리, 제3자 데이터의 범위/자동 수집 가능 여부 확인, 검토한 관계 확대, 실제 추천 사례 평가가 필요하다. 초기 수식의 점수를 승률로 해석하지 않는다. 밴·맵 구간·특전·궁극기·숙련도 등 입력 확장은 이후 과제다.
