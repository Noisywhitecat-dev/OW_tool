# 프로젝트 브리핑

사용자는 대부분의 영웅을 다룰 수 있으며 PC 5대5 경쟁전에서 조합에 맞는 선택을 원한다. 숙련도 필터보다 맵, 티어, 아군 시너지와 상대 대응이 중심이다. 경쟁전 티어는 메타 정보 탭에서 선택한다. 주 사용 환경은 **KR의 넥슨 서버**라는 사용자 표현을 보존한다. 공개 API의 아시아 통계를 한국 전용으로 표시하지 않으며, 서비스/지역 명칭의 공식 대응은 별도 확인한다.

## 첫 단계: 실행 가능한 기반

맵 → 내 역할 → 양 팀 조합 → 상위 5명과 추천 근거의 흐름을 구현한다. 설정 탭에 편집 가능한 조사 프롬프트와 high 조사/low 또는 medium 추천 설정을 둔다. 최신이라고 오인할 수 없는 체험 데이터를 제공한다.

## 데이터 경계

기본 목록과 통계는 확인 가능한 공개 API를 우선한다. GPT는 검색된 사실과 통계의 해석, 상성 근거의 종합을 담당한다. 모든 분석에는 적용 범위, 출처, 패치, 저장 시각, 한계를 남긴다. 실시간 추천에서는 새 검색을 하지 않는다.

## 다음 단계

1. 기존 사이트의 데이터 원천과 공개 비공식 API를 조사하고 검증된 원천을 연동한다.
2. 실제 API 키로 최신 메타 수집의 비용·시간·응답 품질을 측정한다.
3. 알려진 조합 사례로 추천 품질을 평가하고 가중치/프롬프트를 조정한다.
4. 현재 밴, 맵 구간, 영웅 가용성 등 실제 경기 입력을 확장한다.

개발은 의미 있는 작업 단위별 커밋과 PR로 기록한다. 자동 병합은 하지 않는다.
