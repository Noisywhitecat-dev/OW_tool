# 진행 기록 · 2026-09-29 재개

이 문서는 이전 Windows 계정에서 중단한 이후의 최신 상태다. 과거 중단 시점은 Git 기록 `e38eea5`에 남아 있다.

## 반영한 사용자 변경

개인 Windows 앱으로 사용한다. Codex에서 메타를 검토해 JSON으로 주입하고, 앱의 AI는 경기 중 추천만 담당한다. Gemini 무료 티어 지원 모델이 기본이며 실제 요금은 사용자의 Google 프로젝트에 따른다. 앱의 메타 조사·통계 갱신 API와 조사 프롬프트 설정을 제거했다.

## 구현 및 검증

- Electron 휴대용 앱, 단일 로컬 서버, 창 전용 세션 토큰, 네이티브 키 저장 브리지, Windows DPAPI.
- 메타 JSON 검증/적용/재시작 유지. 잘못된 파일은 기존 메타를 교체하지 않는다.
- Gemini 추천 전용 어댑터와 기존 OpenAI 선택 지원. 검색 없음, 재시도 없음, 제공자 자동 전환 없음.
- 추천 중복 요청 합치기, 30분 캐시, 메타/설정 변경 시 무효화, 진행 중 저장과 추천 충돌 방지.
- 개발 전용 OverFast 수집기와 원본 출처/캐시 기록. 53영웅, 30전장 초기 메타 포함.
- 공식 전장 목록 대조: 30개 모두 일치. 제외 7개는 스타디움 전용 5개/일반 경쟁전에서 제거된 격돌 2개.
- 자동 테스트 30개 통과, TypeScript/프로덕션 빌드 성공.
- 패키지 실행 및 Windows DPAPI 스모크 성공. 공통 렌더러의 브라우저 조작 검증.

## 검증하지 않은 범위

실제 Gemini/OpenAI 호출 0회. Astra로 별도 API 기반 메타 정확도 벤치마크를 수행하지 않았다. 네이티브 키 입력 UI 전체, 실제 게임에서의 추천 정확도는 검증하지 않았다. 현재 초기 메타를 완성된 상성 데이터셋이나 신뢰도 입증된 예측 모델로 표현하지 않는다.

Counterwatch·OWTICS 조사 결과는 META_DATA_REVIEW.md에 있다. 이번에는 해당 서비스 전체 데이터를 가져오거나 비공개 API를 연결하지 않았다. 실제 관측/분석/미확인 근거를 분리하며 확장해야 한다.

## 재개 시

현재 브랜치 `feat/ow-compass-foundation`. 작업 디렉터리와 커밋 상태는 `git status`로 재확인한다. 의미 있는 작업 단위별 커밋/PR, 자동 병합 금지. 키 값은 출력하거나 채팅에 요청하지 않는다. 메타 갱신은 앱 내 모델 조사 작업이 아니라 Codex의 수집·검토·JSON 적용 절차다.
