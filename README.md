# OW Compass

PC 5대5 역할 고정 경쟁전용 오버워치 영웅 추천 도구. 한국어 로컬 웹 앱입니다.

맵을 고르면 역할별 추천을 확인하고, 내 역할과 아군 4명·상대 5명을 입력해 상위 5명을 비교합니다. 빈 슬롯을 허용하며 아군과 중복되는 영웅은 추천하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```sh
npm ci
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 키 없이도 명확히 표시된 **체험용 데이터**로 화면과 로컬 추천을 사용할 수 있습니다. 체험용 티어·점수는 실제 메타가 아닙니다.

실제 OpenAI 연동은 `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`를 설정한 뒤 서버를 재시작합니다. API 키는 서버에만 두며 `.env`, 저장된 데이터는 Git에서 제외됩니다.

```sh
npm run build
npm start
```

빌드한 앱은 `http://127.0.0.1:3001`에서 실행합니다. 현재 버전은 개인 PC의 로컬 실행을 대상으로 하며 로그인 없이 공용 서버에 배포하는 구성은 지원하지 않습니다.

## 사용 흐름

1. **메타 정보 · 설정**에서 경쟁전 티어를 선택합니다.
2. 기본 조사 프롬프트를 확인하고 **최신 메타 불러오기**를 누릅니다. 설정 저장 → GPT-6 Astra high 웹 조사 → 구조·참조·검색 출처 검증 → 파일 교체를 한 번에 실행합니다.
3. **영웅 추천**에서 맵, 진영, 내 역할, 팀 조합을 선택합니다.
4. 로컬 점수는 즉시 표시됩니다. **GPT로 추천 정렬**은 Astra low/medium으로 저장된 자료만 재정렬합니다. 웹 검색은 호출하지 않습니다.

같은 메타·맵·조합·모델·추론 노력의 결과는 30분간 재사용합니다. 중복 요청은 합칩니다. API 실패 시 로컬 계산 결과임을 표시합니다.

## 설계

- TypeScript / React / Vite: 한국어 화면, 영웅 선택, 추천 근거, 설정.
- Node.js / Express: OpenAI Responses API, 갱신 작업 상태, 추천 캐시.
- Zod: 입력·모델 응답·저장 파일의 구조와 참조 검증.
- 로컬 JSON 스냅샷: 시즌에 한두 번 갱신하는 개인 앱에 맞춰 단순한 파일 저장 사용. 임시 파일 작성 후 rename에 성공한 경우에만 활성 메타를 바꿉니다.
- 자료 구조: 패치/적용 티어/조사 시각/출처 + 영웅/맵 + 희소 상성·시너지 관계. 없는 관계는 중립으로 처리하고 근거 부족을 표시합니다.

기본 점수는 메타 30%, 맵 25%, 상대 대응 25%, 아군 시너지 20%입니다. 상대/아군 영웅 강도에 비례해 상성/시너지의 가중치를 조정합니다. 이 점수는 승률이 아니며 튜닝을 위한 초기값입니다. 공수·복합 조합 해석은 GPT 정렬에서 반영하며 로컬 점수는 공수 공통입니다.

## 검증과 한계

```sh
npm test
npm run build
```

- 실제 API 키를 넣은 유료 OpenAI 호출은 별도 검증이 필요합니다. 계정별 모델 접근 권한도 필요합니다.
- 메타 연구는 서버 프로세스 내 작업입니다. 브라우저를 닫아도 서버가 살아 있으면 계속되지만 서버 재시작 시 조사 중 작업은 중단됩니다. 기존 저장 파일은 유지됩니다.
- 현재 활성 메타는 하나입니다. 티어를 바꿔 저장만 하면 기존 메타의 적용 티어는 유지되며, **다시 불러오기** 성공 시 교체됩니다.
- 검색 출처 URL과 데이터 참조 검증은 사실 정확성을 보장하지 않습니다. 상성 점수는 통계와 구별되는 분석 결과입니다.
- 캐시/작업은 단일 프로세스 기준입니다. 공개 서비스 전환 시 인증, 사용자별 키/자료 분리, 영속 작업 큐가 추가로 필요합니다.
